# Todo App with Local Storage 📝

Built a simple and functional **JavaScript** task manager to fulfill the freeCodeCamp local storage application lab. This project focuses on handling task creation, deletions, updates, and data persistence.

---

## 🌟 Implemented Features

This project utilizes DOM manipulation and the Web Storage API to satisfy all core requirements:
* **Task Persistence:** Saves, reads, and updates task lists directly within the browser's `localStorage` so data remains intact after a page refresh.
* **Form Handling:** Captures user inputs, handles dates/descriptions, and opens/closes the task modal smoothly.
* **CRUD Operations:** Allows users to create new tasks, clear individual entries, edit existing entries, and delete items from the dashboard.
* **Input Validation:** Ensures empty fields or formatting issues are checked before a task gets pushed to the storage array.

## 🛠️ Project Structure

* **HTML/CSS UI:** Uses the default structured layout provided by the lab to display the task form, dashboard cards, and action buttons.
* **JavaScript Logic:** Handles task array management, state tracking, event listeners, and mapping tasks to JSON strings for data sync.
* **Hosting:** GitHub Pages

## 🚀 How to Open

1. Clone or download this project folder.
2. Double-click the `index.html` file to run the web application right in your browser.
3. Add a few tasks, refresh your browser tab, and confirm that your items stay saved on the screen!
